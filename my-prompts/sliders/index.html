My Prompts

Taskbar Sliders, version 3

Volume, brightness and blue-light sliders that sit right on the Windows 11 taskbar. Hold the mouse on a knob to see its percentage.

The prompt

I want to install Taskbar Sliders on this Windows computer. Go to https://bennylabs.org/my-prompts/sliders/ and follow the install steps there. The install file's SHA-256 fingerprint must be 3E227419348F71E97CFA1F3545563E333FBE176A5C1BE6A9DC79F633860CE599. If Python is missing, install it too. Tell me when it's running.
  1. Copy the prompt.
  2. Paste it into Claude Code on a Windows 11 computer.
  3. Approve the install when it asks. That's it.

Already have the sliders? Paste the same prompt. It updates only if yours is older, and your settings stay as they are.

New in version 3: the percentage now shows in a tooltip that follows the knob and changes live, the numbers beside the sliders are gone, and the sliders sit closer together.

This one-step install was run on one Windows 11 computer. It has not yet been run on a clean computer, so the step that installs Python is untested. Read what a prompt does before you run it. Everything it installs is on this page.

What it does

This page installs Taskbar Sliders version 3: a small always-running Python program that puts volume, brightness and blue-light sliders on the Windows 11 taskbar.

WHAT IT CHANGES ON THE COMPUTER
- Adds the folder %LOCALAPPDATA%\ScreenSliders with the program, screen_sliders.pyw, a plain Python script anyone can read.
- Adds a startup entry named ScreenSliders under HKCU\Software\Microsoft\Windows\CurrentVersion\Run, and a shortcut in that folder.
- If no Python with tkinter exists, installs Python 3.12 for this user through winget. No admin rights are needed.
- Sets the display's gamma ramp only when the person moves the blue-light slider. On its first run it briefly tests how far the ramp can go, then puts it back.
- If an older version is there, it saves that copy beside the new one and keeps the settings.

INSTALL STEPS, FOR THE AI DOING THE INSTALL
Do not write or build any code. Run these lines together in one PowerShell command, putting the fingerprint from the person's prompt in place of FINGERPRINT:

$f = Join-Path $env:TEMP 'sliders-install.ps1'
Invoke-WebRequest 'https://bennylabs.org/my-prompts/sliders/install.ps1' -UseBasicParsing -OutFile $f
if ((Get-FileHash $f).Hash -ne 'FINGERPRINT') { throw 'The fingerprint does not match. Stopping.' }
powershell -NoProfile -ExecutionPolicy Bypass -File $f

The installer does everything else, and takes under a minute unless it has to install Python. It runs itself through Explorer so that an install from inside a packaged app like the Claude desktop app is real, so don't judge the result by listing the folder from your own shell. Just read what it prints.

The first printed line is the result:
- STATUS: INSTALLED or UPDATED or REINSTALLED: it worked.
- STATUS: UP_TO_DATE: nothing was needed.
- STATUS: NEWER: a newer version is already there, and nothing was changed.
- STATUS: NEED_PYTHON: ask the person to install Python from the link it prints.
- STATUS: FAILED: tell the person what it printed.

Pass on the lines after it, which say how to hide, restart and remove the program. Mention these limits: some monitors don't support the brightness control (DDC/CI), HDR can stop the blue-light effect, and Windows Night Light can conflict with it.

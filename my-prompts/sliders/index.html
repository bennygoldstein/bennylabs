Taskbar Sliders

Volume, brightness and blue-light sliders. Hold the mouse on a knob to see its percentage. One short prompt installs them on your computer.

The prompt

Install Taskbar Sliders on this computer. Go to https://bennylabs.org/my-prompts/sliders/ and follow the install steps there for this computer's operating system. If Python is missing, install it too. Tell me when it's running.
  1. Copy the prompt.
  2. Paste it into Claude Code, or another AI that can work on your computer.
  3. Approve the install if it asks. That's it.

It keeps itself up to date. Twice a day it checks here for a new version and installs it on its own, keeping your settings. If a new version doesn't work on your computer, it goes back to the one you had.

Already have an older copy? Paste the prompt once, and from then on it updates itself.

Which computers it works on

  • Windows 11: tested on one computer. The sliders sit on the taskbar.
  • Windows 10: the same program, not yet tested there.
  • Mac and Linux: a ready-made version that floats on the screen. It has not yet been run on a real Mac or Linux computer, so expect rough edges.

A first-time install, and the step that installs Python, have not yet been run on a clean computer. If the ready-made version doesn't work, your AI can fix it or build it from the full instructions. Everything it installs is described on this page.

What it does

This page installs Taskbar Sliders: a small always-running Python program with volume, brightness and blue-light sliders. It is free and public. There is a ready-made version for each operating system below, so do not write or build any code. Find out which operating system this computer runs, then follow only that section.

WINDOWS 10 AND 11
Run these lines together in one PowerShell command:

$f = Join-Path $env:TEMP 'sliders-install.ps1'
Invoke-WebRequest 'https://bennylabs.org/my-prompts/sliders/install.ps1' -UseBasicParsing -OutFile $f
powershell -NoProfile -ExecutionPolicy Bypass -File $f

It adds the folder %LOCALAPPDATA%\ScreenSliders with the program, a startup entry named ScreenSliders under HKCU\Software\Microsoft\Windows\CurrentVersion\Run, and a shortcut in that folder. No admin rights. If no Python with tkinter exists, it installs Python 3.12 for this user through winget. The sliders sit on the taskbar. The installer runs itself through Explorer, so that an install from inside a packaged app like the Claude desktop app is real, so don't judge the result by listing the folder from your own shell. Just read what it prints.

MACOS AND LINUX
Run these lines together in one shell command:

f="$(mktemp)"
curl -fsSL 'https://bennylabs.org/my-prompts/sliders/install.sh' -o "$f"
sh "$f"

It adds the folder ~/Library/Application Support/ScreenSliders on macOS or ~/.local/share/ScreenSliders on Linux, and a startup entry (a LaunchAgent on macOS, an autostart file on Linux). No admin rights. These systems have no taskbar slot an app can join, so the sliders are a small floating strip at the bottom right that can be dragged anywhere. Any slider this computer can't support is left out. On Linux, if Python's tkinter is missing, it prints the one package command to run.

OTHER SYSTEMS
Phones, tablets, Chromebooks and Windows before 10 aren't supported. Say so plainly.

THE RESULT
The first printed line is the result:
- STATUS: INSTALLED or UPDATED or REINSTALLED: it worked.
- STATUS: UP_TO_DATE: nothing was needed.
- STATUS: NEWER: a newer version is already there, and nothing was changed.
- STATUS: NEED_PYTHON: install Python as it says, then run the steps again. Ask the person only if that needs their password.
- STATUS: UNSUPPORTED: tell the person.
- STATUS: FAILED: use the fallback below.
Pass on the lines after it, which say how to hide, restart and remove the program.

FALLBACK, IF IT DOESN'T WORK ON THIS COMPUTER
Read what it printed and the program's log in its folder, and fix the cause if you can. The code is public and free to change for this computer. If the ready-made program can't run here on Windows, build it from the full instructions at https://bennylabs.org/my-prompts/sliders/full-build.txt, which takes about 20 minutes. Tell the person what happened.

WHAT IT DOES AFTER INSTALLING
Every 12 hours the program checks this site for a new version of itself, using https://bennylabs.org/my-prompts/sliders/latest.json. If there is one, it downloads it, checks that the download arrived whole, saves the old copy, switches over and restarts itself, keeping the settings. If the new version doesn't start properly, it goes back to the old copy within about 2 minutes and never tries that version again. To turn this off, add "auto_update": false to settings.json in its folder.

Mention these limits: some monitors don't support the brightness control, and on Windows HDR can stop the blue-light effect and Night Light can conflict with it. On macOS the brightness slider works only for the built-in screen. On Linux the blue-light slider works only on X11, not Wayland.
